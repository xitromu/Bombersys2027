# BOMBERSYS

Bomberman 2005 года (Visual C++ 6.0 + MFC), возрождённый как браузерная игра.
Правила и графика — из оригинала, враги и рост сложности — новые.

- Играть можно одному, вдвоём за одной клавиатурой или вдвоём по сети — на двух ноутбуках в одной Wi-Fi.
- Своя музыка в духе игровых автоматов 80–90-х, звуки взрывов и призраков, голоса ведущего.
- С каждым уровнем врагов больше, они замечают игрока издалека и всё лучше его преследуют.
- Сложность растёт плавно, чтобы до 10-го уровня мог дойти любой игрок.

## Скачать и играть (Windows)

1. Откройте [последний релиз](https://github.com/xitromu/Bombersys2027/releases/latest) и скачайте **BOMBERSYS.exe**.
2. Запустите его двойным щелчком — игра откроется в браузере. Ничего устанавливать не нужно.
3. Чтобы выйти — закройте чёрное окно сервера.

Windows может предупредить «Windows защитила ваш компьютер» — у файла нет цифровой подписи.
Нажмите **«Подробнее» → «Выполнить в любом случае»**.

## Запуск из исходников

Нужны только Python 3.11+ и [uv](https://docs.astral.sh/uv/) (`pip install uv`).

```
start.bat
```

или вручную:

```
cd backend
uv run bombersys
```

Откроется браузер на http://127.0.0.1:8000. Остановить сервер — `Ctrl+C` в окне консоли.

При первом запуске uv сам создаст окружение `backend/.venv` и скачает библиотеки (FastAPI, uvicorn).

## Управление

По умолчанию:

| | Ходить | Бомба |
|---|---|---|
| Иван | `W` `A` `S` `D` | `Пробел` |
| Колян | стрелки | `Enter` |

`P` — пауза, `Esc` — выход в меню. В игре на одного Иваном можно управлять обеими раскладками.

`M` — звук: «звук и музыка» → «без музыки» → «без звука»; `−` и `+` — громкость шагами по 10 %
(или кнопки в правом нижнем углу). Выбор запоминается в браузере.

Клавиши меняются в меню: **K — настроить клавиши**. Настройка запоминается в браузере.

Повороты прощают промах почти на клетку. Если нажать поворот раньше прохода, не отпуская
прежнюю стрелку, герой дойдёт до прохода и свернёт сам.

Кнопка **«На весь экран»** — в правом нижнем углу окна.

## Игра по сети (два ноутбука)

1. Первый игрок запускает BOMBERSYS.exe и выбирает в меню **3 — создать игру по сети**.
   На экране появится адрес вида `http://192.168.1.23:8000`.
2. Второй игрок в той же Wi-Fi открывает этот адрес в браузере (устанавливать ничего не нужно)
   и нажимает **4 — присоединиться**.
3. Первый играет Иваном, второй — Коляном, каждый своими клавишами. Если кто-то вышел — партия заканчивается.

При первом запуске Windows спросит про доступ к сети — разрешите. Если второй не подключается:
сеть должна быть «частной» (или разрешён доступ и в общественных сетях), а VPN — выключен.

## Правила

- Бомба взрывается крестом на 2 клетки. Огонь поджигает соседние бомбы — быстрой волной,
  от поставленной раньше к поставленной позже.
- Огонь сжигает открытые бонусы (но не те, которые сам только что открыл).
- Если огонь попал в открытую дверь, она запирается, пока не убиты все враги.
- На уровне бывают враги посильнее (на ступень «цветом» выше). Очки за врага:
  зелёный 100, оранжевый 250, красный 500, фиолетовый 1000.
- Если погибнуть вплотную к бомбе, смерть «эпичная»: героя отбрасывает взрывом. От дальнего языка пламени — обычная.
- Под стенами прячутся дверь (выход на следующий уровень) и бонусы: сундук, мешки, бриллианты,
  +1 бомба, жизнь — или ловушка «смерть». Каждые 5000 очков дают жизнь.
- Уровень заканчивается, когда все игроки ушли в дверь или погибли. Если никто не ушёл, уровень переигрывается.
- После гибели — короткая ободряющая фраза, после каждого пройденного уровня — хокку на правой панели.
  Все тексты лежат в [frontend/js/texts.js](frontend/js/texts.js), дописывайте свои.

## Как устроено

```
Браузер (Phaser)  ── нажатия клавиш ──▶  Сервер (Python, FastAPI)
      ▲                                        │ 30 раз в секунду пересчитывает игру
      └──────── состояние игры (JSON) ◀────────┘
                     WebSocket
```

Все правила живут на сервере, браузер только рисует. Поэтому игровую логику можно
читать и менять на Python, а позже добавить игру по сети.

## Частые действия

| Что нужно | Команда (из папки `backend`) |
|---|---|
| Запустить игру | `uv run bombersys` |
| Прогнать тесты | `uv run pytest` |
| Посмотреть таблицу сложности | `uv run python -m app.game.difficulty` |
| Пересобрать картинки из BMP | `python ../tools/convert_assets.py` |
| Послушать и проверить звуки | запустить игру и открыть в браузере `/sounds.html` |
| Поменять номер версии | `version` в `backend/pyproject.toml` (меню показывает его внизу) |
| Собрать BOMBERSYS.exe | `packaging\build_exe.bat` → `backend\dist\BOMBERSYS.exe` |

## Сложность

Всё в [backend/app/game/difficulty.py](backend/app/game/difficulty.py). Вдвоём добавляется один враг.

| Уровень | Врагов | Замечают с, клеток | Ищут путь в обход стен | Скорость (игрок — 3.2) |
|---|---|---|---|---|
| 1 | 2 | 2.5 | никогда | 1.5 |
| 5 | 4 | 4.5 | в 30% решений | 1.78 |
| 10 | 7 | 7 | в 80% решений | 2.13 |
| 15 | 10 | 9 | в 85% решений | 2.48 |

Со 2-го уровня каждый третий враг — «сильный»: на ступень выше цветом, быстрее, зорче и умнее.
С 4-го уровня враги начинают обходить бомбы и огонь. С каждым уровнем они дольше
помнят, где видели игрока. Цвет врагов меняется каждые 3 уровня: зелёные → оранжевые → красные → фиолетовые.

## Про старую версию

`legacy/UMIRAYUT/Release/B.exe` — оригинальная игра. Путь к картинкам в ней зашит
(`C:/BOMBERSYS/`), поэтому для запуска картинки из `legacy/` нужно временно скопировать
в `C:\BOMBERSYS`.

Заставка оригинала (кадр из фильма «Мумия») убрана — и из игры, и из репозитория.
Картинка GAME OVER и портреты героев пока оставлены как есть.
